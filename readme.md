# 🚀 About AtmoonPay

**AtmoonPay** is a modern payout platform that enables businesses to:

* Manage wallet balances
* Add and verify beneficiaries
* Perform single and bulk payouts
* Track transactions in real-time
* Request wallet funding and withdrawals
* Download reports and settlement data

The Merchant Panel is designed to provide a seamless experience for businesses to handle all payout operations from a single dashboard.
